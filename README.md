# gRPC Learning - E-commerce Microservices

A hands-on project to understand gRPC using Java 21 and Maven.

## Microservices

- Order Service
- Payment Service
- Inventory Service

## Technologies

- Java 21
- Maven
- gRPC
- Protocol Buffers
- IntelliJ IDEA

## Learning Objectives

- Understand gRPC architecture
- Implement gRPC clients and servers
- Define contracts using Protocol Buffers
- Implement synchronous service communication
- Explore error handling and streaming
